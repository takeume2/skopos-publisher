# Skopos Publisher ロゴアセット

2026-11-19 決定の正式ロゴセットです。

## ファイル

| ファイル | 内容 | 用途 |
|---|---|---|
| `skopos-logo.svg` / `.png` | Hクリーン版（照準マーク＋Skopos／細罫／PUBLISHER） | 明るい背景用。READMEヘッダー、アプリのタイトルなど |
| `skopos-logo-dark.svg` / `.png` | 同上・白文字版 | 暗い背景用 |
| `skopos-mark.svg` / `.png` | A 照準マーク単体（1024px） | アイコン、favicon元画像 |
| `skopos-mark-256.png` | 照準マーク 256px | 小サイズ用 |
| `skopos-page.svg` / `.png` | C ページ＋照準マーク | 明るい背景用。文書・PDFまわりの装飾など |
| `skopos-page-dark.svg` / `.png` | 同上・白版 | 暗い背景用 |

## 仕様

- SVG の文字はアウトライン化済み（フォント環境に依存しません）
- PNG はすべて背景透過
- PNG サイズ: logo 幅1600px / mark 1024px（256px版も同梱） / page 高さ800px

## カラー

- ティール（照準・PUBLISHER）: `#0ABAB5`
- インク（Skopos・罫）: `#0F172A`
- 紺背景の目安: `#0B1526`
- 白文字版の文字色: `#FFFFFF`
