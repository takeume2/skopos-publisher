# Markdown 記法・YAML フロントマター リファレンス

Skopos Publisher で利用できる YAML フロントマター項目、独自ディレクティブ記法、および出力ファイル名規則の詳細リファレンスです。

---

## 1. YAML フロントマター

Markdown の先頭に `---` で囲んで記述します。右側の「ドキュメント設定」ドロワーからも GUI で双方向編集できます。

### 基本情報・表紙・裏表紙

| キー | 型 / 値 | 説明 |
| :--- | :--- | :--- |
| `title` | 文字列 | 文書タイトル。表紙では `\n`・改行・`<br>` で任意改行可（ヘッダーやファイル名では自動的に 1 行化） |
| `subtitle` | 文字列 | 表紙のサブタイトル |
| `recipient` | 文字列 | 配布先（顧客名・部署名など。表紙に表示） |
| `author` | 文字列 | 作成者・組織名 |
| `date` | 文字列 | 作成日（例: `"2026-11-26"`）。出力ファイル名の `{date}` にも使用 |
| `cover` | `true` / `false` | 表紙ページの生成有無 |
| `cover_image` | 文字列 | 表紙の背景画像（共通画像 ID または URL） |
| `cover_overlay` | `light-fade` / `dark-fade` / `none` | 表紙背景画像上のオーバーレイ・文字色モード |
| `back_cover` | `true` / `false` | 裏表紙（奥付）ページの生成有無 |
| `back_cover_image` | 文字列 | 裏表紙の背景画像 |
| `back_cover_text` | 文字列 | 裏表紙の奥付テキスト。YAML ブロックリテラル（`\|-`）を使うと複数行の改行をそのまま反映可能 |

```yaml
back_cover_text: |-
  株式会社サンプルテクノロジー
  システムアーキテクチャ推進室
  東京都千代田区1-1
  Copyright (c) 2026 Sample Technology Inc. All Rights Reserved.
```

### 用紙・目次・デザインテーマ

| キー | 型 / 値 | 説明 |
| :--- | :--- | :--- |
| `page_size` | `A4` / `A5` / `B5` / `Letter` | 用紙サイズ |
| `orientation` | `portrait` / `landscape` | 印刷の向き（縦 / 横） |
| `toc` | `true` / `false` | 自動ページ番号付き目次の生成有無 |
| `toc_depth` | `1` / `2` / `3` | 目次に含める見出しの深さ（H1〜H3） |
| `theme` | `business` / `technical` / `minimal` | プリセットデザインテーマ |
| `primary_color` | `#RRGGBB` / `""` | プライマリカラーの上書き（空文字でテーマ標準） |
| `accent_color` | `#RRGGBB` / `""` | アクセントカラーの上書き（空文字でテーマ標準） |
| `heading_highlight` | `tinted` / `solid` / `none` | 見出しハイライトの表示スタイル |
| `font_family` | `theme` / `sans` / `serif` | 本文フォント |
| `font_size` | `9` 〜 `12` | 本文フォントサイズ（pt） |
| `line_height` | `1.4` 〜 `2.0` | 本文の行間 |

### 機密表示・ロゴ・ヘッダー／フッター

| キー | 型 / 値 | 説明 |
| :--- | :--- | :--- |
| `confidential_mode` | `none` / `standard` / `strict` | 機密表示モード（`standard`: ヘッダー・フッター合成、`strict`: ＋対角線全面透かし） |
| `confidential_label` | 文字列 | 機密ラベル文字列（例: `CONFIDENTIAL`, `社外秘`, `取扱注意`, `極秘`） |
| `logo` | 文字列 | ロゴ画像（共通画像 ID または URL） |
| `logo_position` | `cover-and-header` / `cover-only` / `header-only` | ロゴの表示位置 |
| `header_left` / `header_right` | 文字列 | 左右ヘッダー文字列 |
| `footer_left` / `footer_right` | 文字列 | 左右フッター文字列 |

ヘッダー／フッターで使用できる変数：`{title}`, `{date}`, `{author}`, `{recipient}`, `{page}`, `{pages}`

## 2. 独自ディレクティブ・表現記法

コードブロック（```` ``` ````）やインラインコード（`` `...` ``）内に記述したディレクティブは変換されずリテラルとして表示されます。

### 中扉（章扉）

章の区切りに独立した章扉ページを挿入します。H1 見出しと直後のリード文が章扉として組版され、目次にも自動収録されます。

```markdown
<!-- chapter -->

# 1. エグゼクティブサマリー

本章の概要やリード文をここに記述します。

<!-- /chapter -->
```

### 強制改ページ

任意の箇所で改ページを挿入します。

```markdown
<!-- pagebreak -->
```

または

```markdown
\newpage
```

### KPI / サマリーカード

箇条書きリストを印刷セーフな CSS Grid 型のカードブロックへ変換します。列数は項目数から自動決定（2〜4 列）されるほか、`<!-- cards: 3 -->` や `<!-- cards cols=4 -->` で明示指定できます。

各項目は `ラベル | 数値 | 補足 | アクセント種別（任意）` の形式で記述します。

```markdown
<!-- cards -->

- 評価項目総数 | 42件 | 前回診断比 -8件 | info
- 緊急・高リスク | 7件 | Critical 2 / High 5 | critical
- セキュリティ適合率 | 92.9% | 目標 90% 以上達成 | success
- 目標稼働率 (SLA) | 99.95% | 冗長構成検証済み | primary

<!-- /cards -->
```

利用可能なアクセント種別：`critical`, `high`, `medium`, `warning`, `low`, `success`, `info`, `neutral`, `primary`, `accent`, `none`、または `#RRGGBB` 形式のカスタム色。

### カラーバー（割合積み上げ棒グラフ）

各項目の数値を割合バーと凡例・合計値付きで描画します。

```markdown
<!-- colorbar: 完了=28, 進行中=9, 未着手=5 -->
```

- `Critical`, `High`, `Medium`, `Low`, `Info`, `完了`, `進行中`, `未着手` などのセマンティック名には標準色が自動割り当てされます。
- `項目A=40(#2563eb), 項目B=60(#10b981)` のように `#RRGGBB` で色を個別指定できます。

### 円グラフ・ドーナツグラフ（純 SVG）

JavaScript のグラフライブラリに依存しない純 SVG で描画されるため、Paged.js の印刷プレビューや PDF 出力でもくっきりとしたベクター品質を維持します。

```markdown
<!-- donut(検出事項の重要度別内訳): Critical=2, High=5, Medium=12, Low=18, Info=5 -->
```

```markdown
<!-- pie(リクエスト処理レイテンシ内訳［ms］): 認証・認可=12, アプリ処理=28, DBアクセス=35, ネットワーク=15 -->
```

> タイトルは `donut(タイトル): ...` / `pie(タイトル): ...` の形式で指定します（タイトル文字列の中に半角 `)` は含めないでください）。色指定のルールはカラーバーと共通です。

### 重要度・ステータスバッジ

コロンで囲んだキーワードがインラインバッジに変換されます（大文字・小文字は区別されません）。

- **重要度**: `:Critical:` / `:緊急:`、`:High:` / `:高:`、`:Medium:` / `:中:`、`:Low:` / `:低:`、`:Info:` / `:参考:`
- **ステータス**: `:Scoping:`、`:Active:`、`:Draft:`、`:Final:`、`:Closed:`

### 見出しハイライト

- 見出し（H1〜H3）の中にバッジを含めると、バッジ種別に応じたハイライト色が自動適用されます。
- 見出し末尾に `<!-- hl: 種別 -->` を記述して明示指定することもできます。

```markdown
## 2.2 認証トークンの有効期限検証不備 :High:
## 2.3 監査ログの改ざん検知設計 <!-- hl: info -->
```

指定可能な種別：`critical`（`danger`）, `high`, `medium`（`warning`）, `low`（`success`）, `info`, `scoping`, `neutral`, `primary`, `accent`, `none`

### コールアウト（7 種類・カスタムタイトル対応）

引用ブロックの先頭にマーカーを記述します。1 行目に任意のカスタムタイトルを併記できます。

```markdown
> [!SUMMARY] 総合評価サマリー
> セクションの要点をまとめます。

> [!SUCCESS] 基準適合の確認
> 達成した基準や確認結果を記述します。

> [!CAUTION] 必須是正事項
> 重大なリスクや禁止事項を記述します。
```

対応マーカー：`[!NOTE]`, `[!SUMMARY]`（`[!ABSTRACT]` も同義）, `[!SUCCESS]`, `[!TIP]`, `[!IMPORTANT]`, `[!WARNING]`, `[!CAUTION]`

### ファイル名付きコードブロック・数式・GFM

- **ファイル名付きコードブロック**: 言語名の後ろに `:ファイル名` を付けるとヘッダーバー付きで表示されます。
  ````markdown
  ```ts:src/lib/formatter.ts
  export const version = "1.0.0";
  ```
  ````
- **数式（KaTeX）**: インライン数式 `$E = mc^2$` およびブロック数式 `$$ ... $$` に対応しています。
- **GFM**: テーブル（列揃え対応）、タスクリスト（`- [x]` / `- [ ]`）、取り消し線、脚注（`[^1]`）に対応しています。

### 画像の埋め込み

- エディタへ画像ファイルをドラッグ＆ドロップすると、ドロップしたカーソル座標へ自動で Markdown 記法（`![name](asset:...)`）が挿入されます（誤読込防止のため画像ファイル以外のドロップはブロックされます）。
- クリップボードからの画像貼り付けや、フォーマットバーの画像ボタンからも挿入できます。
- 「フォルダ読込」で `.md` と画像フォルダ一式を読み込んだ場合は、相対パス参照の画像も自動解決されます。

## 3. 出力ファイル名の自動命名規則

右設定ドロワーの **「出力ファイル名」** セクションで、PDF 出力（ブラウザ印刷ダイアログの初期ファイル名）および `.md保存` のファイル名規則を設定・プレビュー・コピーできます。設定はブラウザの IndexedDB に保存され、すべての文書へ一貫して適用されます。

- **既定テンプレート**: `{date}_{title}_{confidential}`
  - 機密表示が有効な場合: `20261126_文書タイトル_CONFIDENTIAL.pdf`（/ `.md`）
  - 機密表示が `none` の場合: `20261126_文書タイトル.pdf`（不要な `_` は自動省略）
- **プリセット**:
  - 標準（`{date}_{title}_{confidential}`）
  - 日付＋タイトル（`{date}_{title}`）
  - タイトルのみ（`{title}`）
- **利用可能な変数**: `{date}`（`YYYYMMDD` 正規化。未指定時は当日日付）, `{title}`, `{confidential}`, `{author}`, `{recipient}`
